Aggiungi compiti

Incolla qui il testo dei file «Compiti per…» (anche più file di seguito). Legge materia, docente, data di assegnazione e giorno di consegna.

Le materie da studiare hanno due spunte: prima «Studiato», poi «Ripassato» per l'orale. Le spunte sui compiti vengono salvate sul browser di questo dispositivo.

Ogni tanto premi «Salva backup»: se il browser cancella i suoi dati, con «Ripristina» recuperi le spunte. Per inviare i nuovi compiti, usa il pulsante «Genera link compiti» oppure aggiorna il file online: lo studente potrà continuare a usare la scheda mantenendo i suoi progressi.
